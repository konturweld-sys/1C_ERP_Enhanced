# Единый Telegram webhook для ERP и УБТ

Интеграция использует один webhook Telegram на одного бота. Адрес принимает HTTP-сервис расширения ERP `ЕРП_TelegramWebhook`, после чего адаптер:

1. проверяет имя бота и секретный заголовок штатным методом УБТ;
2. преобразует входящие updates штатным методом УБТ;
3. обрабатывает сообщения `/start <код>` в ERP, создаёт чат в справочнике УБТ при его отсутствии и отправляет ответ через `УБТ_РаботаСБотамиTelegram`;
4. исключает обработанные `/start` из дальнейшей передачи, чтобы УБТ не отвечал на них сообщением «неизвестная команда»;
5. передаёт все остальные сообщения штатному обработчику УБТ `ОтветитьНаПолученныеСообщения()`.

Токен Telegram хранится только в УБТ. Исходный код УБТ не изменяется.

## Настройка бота в УБТ

В карточке справочника **Боты Telegram**:

1. Установить вариант взаимодействия **Вебхук**. Не включать регламентный опрос `getUpdates`.
2. В поле **Адрес вебхука** указать полный URL шлюза ERP:

   `https://<публичный-домен>/<путь-публикации-базы>/hs/erp-tg/webhook/<код-бота-УБТ>`

   Например, если база опубликована в корне домена:

   `https://erp.example.ru/hs/erp-tg/webhook/my_bot`

3. Заполнить поле **Секрет вебхука**. УБТ использует это значение при установке webhook и проверяет его при приёме updates.
4. Сохранить карточку бота.
5. Нажать в УБТ **Установить вебхук**.

В поле **Адрес вебхука** нужно указать именно адрес ERP-шлюза `/hs/erp-tg/webhook/<код-бота>`, а не штатный адрес УБТ `/hs/telegram-bot-management/webhook/<код-бота>`.

Кнопка УБТ вызывает Telegram Bot API `setWebhook` с URL из поля карточки. Не устанавливать второй webhook отдельной командой или из другого приложения: Telegram хранит только один активный webhook на бота, и последняя установка заменяет предыдущую.

## Разделение обработки

- `/start <код>` — ERP: проверка кода, идемпотентность по Telegram Update ID, аудит и жизненный цикл привязки.
- Остальные сообщения и команды — УБТ: штатная обработка сценариев и ответов.
- Исходящие уведомления — через программный интерфейс УБТ. ERP не обращается к Telegram Bot API напрямую и не хранит токен.

Шлюз использует объекты УБТ версии `v0.18.0`. Обновление УБТ следует отдельно сверять с используемыми экспортными методами и структурой таблицы входящих сообщений.

## Границы проверки

Изменения в репозитории не устанавливают webhook в Telegram и не меняют настройки уже созданного бота. После загрузки расширения в Конфигуратор нужно указать URL шлюза в карточке УБТ и установить webhook средствами УБТ. Функциональные тесты не выполнялись.
