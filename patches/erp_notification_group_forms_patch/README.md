Статус: подготовленный кандидат, не импортирован и не проверен Конфигуратором 8.3.27.

## Состав подготовленного пакета
Ранее сформирован архив-кандидат `erp_notification_group_forms_patch.zip` с четырьмя формами:
- ФормаЭлемента
- ФормаСписка
- ФормаВыбора
- ФормаМножественногоВыбора

Архив содержит метаданные форм и `Ext/Form.xml`. UUID самого справочника не меняется. UUID форм были сгенерированы, поскольку исходные UUID форм в выгрузке отсутствуют.

## РазблокированиеРеквизитов
В текущем проекте не обнаружены собственный контракт блокируемых реквизитов, вызовы API запрета редактирования, функция менеджера или модуль формы. Поэтому прикладную форму `РазблокированиеРеквизитов` не создаём: стандартный сценарий должен использовать общую форму БСП 3.1.11.466.

В исходном XML справочника остаётся объявление `<Form>РазблокированиеРеквизитов</Form>`. Его следует удалить при интеграции подготовленных форм.

## Ограничения
Архив прошёл только проверку well-formed XML и целостности ZIP. Это не подтверждает совместимость свойств форм, динамических списков и параметров выбора с Конфигуратором 8.3.27.1859. Функциональные тесты не выполнялись.

Не импортировать этот кандидат в рабочую ERP. Следующий этап — интегрировать XML-файлы в дерево выгрузки, согласовать `ConfigDumpInfo.xml`, затем проверить загрузку в отдельной тестовой копии.
